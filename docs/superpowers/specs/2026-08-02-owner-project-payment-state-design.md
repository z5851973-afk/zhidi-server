# 业主项目卡片付款状态同步设计

## 目标

业主端“我的家”顶部项目卡片必须根据该预约最新支付单展示真实付款状态，不能在已经付款后继续显示“去支付”。

## 状态规则

- 没有支付单或支付单为 `PENDING`：显示“去支付”。
- 支付单为 `OWNER_REPORTED_PAID`：显示“待师傅确认收款”。
- 支付单为 `PAID`：显示“已支付 · 查看记录”。
- 点击按钮继续进入统一付款详情页，查看金额、报价明细和付款记录。

## 数据流

`MyHomePage` 已通过 `GET /api/v1/payment/orders` 加载支付单，并按 `bookingId` 保留最新一笔。将当前特色项目对应的 `PaymentOrderModel` 传入 `_ProjectWorkbenchCard`，复用候选详情卡片现有的付款状态判断，不新增本地假状态，也不修改后端。

## 异常处理

支付记录请求失败时保留当前缓存；没有可用支付记录时维持“去支付”，点击后由付款详情页重新请求服务器。

## 验证

新增 Widget 回归测试，覆盖 `COMPLETED + OWNER_REPORTED_PAID` 和 `COMPLETED + PAID` 的顶部项目卡片文案，并运行相关测试、静态检查、构建安装及模拟器截图复验。
