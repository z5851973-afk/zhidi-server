# 报价数量空值输入设计

## 目标

工人在报价单中编辑已勾选项目的数量时，删除最后一个数字后，输入框保持空白、保持展开且保持输入焦点，方便直接输入新数量。

## 状态设计

- “项目是否勾选”与“项目数量”使用两个独立状态，不再用 `数量 > 0` 判断项目是否勾选。
- 勾选项目时默认数量为 `1`。
- 已勾选项目的数量允许临时为空；空值参与金额计算时按 `0` 处理，但输入框仍显示空白。
- 数量为空或等于 `0` 时，项目继续保持勾选，输入框不收起。
- 用户取消勾选时才移除项目及其数量状态。

## 输入与金额规则

- 删除最后一个字符后不自动补 `0`，不自动失焦。
- 空白后输入数字时直接显示新数字，不产生前导零。
- 人工/材料小计和报价总价随输入实时计算；空值按 `0`。
- 没有任何大于 `0` 的有效数量时，提交按钮保持禁用。

## 验证

- Widget 回归测试覆盖：勾选项目、删除数量至空白、输入框仍存在且为空、总价归零、重新输入后总价恢复。
- 运行报价页聚焦测试与 Flutter 静态检查。
- 在工人端模拟器复验真实键盘删除和重新输入。
