# 工人端隐藏平台服务费设计

## 目标

工人端不展示业主支付给平台的 10% 服务费。工人只看到与自己有关的工程款、到账状态、可结算金额和履约质保金；业主端、管理端和后端财务数据保持不变。

## 可见性规则

以下工人端入口不得出现“平台服务费”、服务费比例或服务费金额：

- 结算列表和费用卡片；
- 确认收款弹窗与成功提示；
- 付款相关消息通知；
- 工人订单详情、完工档案和收入详情；
- 新资金模型和历史资金模型的工人端页面。

新订单工人端展示：

- 本单应收工程款；
- 工程款是否已上报、是否已确认到账；
- 工人独立履约质保账户余额和待补充金额。

历史订单工人端展示：

- 报价清单总价；
- 可结算金额；
- 历史订单质保金金额。

历史订单仍按原资金模型计算，但不展示业主另外承担的平台服务费。

## 实现边界

- 只修改 Flutter 工人端文案和展示条件，不修改业主端 UI。
- 不删除后端 `platformServiceFee` 等字段，不改变付款金额、状态机、数据库或管理端对账能力。
- 工人端仍可查看人工与材料报价明细，但报价明细不附加业主的平台服务费。
- 避免只隐藏截图中的单行：所有工人端付款入口统一执行相同可见性规则。

## 测试

- 新资金模型结算页断言不显示任何平台服务费文字、比例或金额。
- 历史资金模型结算页断言不显示平台服务费，同时保留报价总价、可结算金额和历史质保金。
- 工人付款消息和确认收款反馈不得包含平台服务费。
- 运行相关 Widget 测试、Flutter 全量测试、`flutter analyze`，并重新构建 worker debug APK。

## 非目标

- 不改变业主支付平台服务费的业务规则。
- 不接入真实微信支付。
- 不部署后端、不迁移数据库、不清理历史订单。
