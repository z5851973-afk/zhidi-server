售后与质保金管理台

用于处理业主售后、扣减或释放 10% 质保金。页面只负责运营操作，所有权限仍由后端管理员 JWT 校验。

管理员账号必须已经在后端拥有 ADMIN 角色；普通业主或工人验证码不能进入管理台。

提示：当前后端仍是无状态 JWT。页面不会存密码，只把 token 保存在本机浏览器 localStorage。
